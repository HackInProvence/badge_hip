FSK Buzzer Link

Liaison acoustique 4‑FSK entre deux machines : l'une émet au haut‑parleur, l'autre décode au micro. Mêmes réglages sur les deux PC. Un seul PC suffit pour un premier essai (haut‑parleur → micro).

4 tons, codage Gray (00·01·11·10), 2 bits par symbole. Trame : mot de synchro 28 symboles · longueur en Hamming(8,4) · [données + CRC‑8] en code convolutif K=7 r=½, entrelacés. Réception : Goertzel fenêtré sur un symbole entier par pas de ¼, bruit estimé sur les bins de garde entre les tons, Viterbi à décision douce, combinaison des répétitions.
