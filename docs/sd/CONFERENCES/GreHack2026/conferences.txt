jour: 2026-11-13
titre: Pretend to be NOR: SPI Flash Emulation on Raspberry Pi Pico
orateur: Paul Viel
resume: This submission introduces a cost-effective SPI flash emulation tool built on the Raspberry Pi RP2040 microcontroller. Debugging hardware and exploiting Time-of-Check-Time-of-Use (TOCTOU) vulnerabilities on SPI flash typically involve slow, repetitive physical erase and reprogram cycles. The tool eliminates this significant bottleneck.

jour: 2026-11-13
titre: BinQL: a CodeQL extension to binary format
orateur: Raphaël Louvigny, Maxime Turlure
resume: Variant analysis tools excel at finding similar bugs in source code. But move to binaries and those tools disappear, forcing analysts into a slow and tedious manual hunt. We reverse-engineered CodeQL's undocumented extractor internals and created BinQL: a CodeQL extractor for binaries. Built on IDA Pro's decompiler, BinQL queries decompiled code the same way you would query source code.

titre: Cracking protobufs: schema recovery, type inference, anomaly detection
orateur: Frederic Ruget
resume: Protocol Buffers are ubiquitous in modern infrastructure - gRPC services, cloud platforms, mobile apps - yet they are routinely treated as opaque. The standard tool, protoc --decode, requires the original descriptors and message type and silently normalizes non-canonical encodings, making wire-level anomalies invisible.
